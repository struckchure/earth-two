# Earth Two world docs

Earth Two is a multiplayer, open-world game. Players arrive in debt on an
abandoned colony and work their way up through contracts, trade and
reputation. A ship from Earth is coming to take the planet back.

Each doc below covers one topic and can be read on its own.

| Doc | Read it for |
