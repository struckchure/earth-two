# Glossary

| Term | Meaning |
| --- | --- |
| AL | Years After Landfall. The game opens in 88 AL. See [History](history.md). |
| The Accord | The 41 AL agreement that created the Exchange |
| Bond | Money a contract-taker puts up, lost on default |
| Collection | A filed contract to recover a defaulted debt |
| Corvane | The bankrupt colony company whose charter expires in 90 AL |
| Drifter | An independent long-haul freighter, and the only link to Earth |
| Filed / off-book | Registered with the Exchange (legal) / not registered (illegal) |
| Filters | Air-filter cartridges, used as currency in the Fringe |
| The Hull | The grounded colony ship *Second Light*, now the city's core |
| Landfall | The first city, built around the Hull. Also the colony's founding, in 0 AL. |
| Late Arrivals | Migrants who came on drifters, paying for passage in debt. Every player starts as one. |
| Marks | Exchange credit, the legal currency |
| Quiet | Off-book reputation |
| The Red | What the colonists call the planet. "Earth Two" is only its name on the charter. |
| Scrip | Old Corvane company money |
| Sealed | The highest licence tier; can file on behalf of a faction |
| Season | Three real months. The world resets at the end, and the richest player wins a share of the economy. |
| Slot | A player's place in the population-capped world. Can be sold. |
| Standing | Filed reputation |
| Transfer | A filed sale of a player's slot. The buyer inherits everything the character has and owes, and picks only a new name and look. |
| Walking out | Leaving the game for good. The character goes past the dome line and isn't seen again, and their slot opens. |
